# Базовый код человека: локальный прототип бота

Развлекательный нумерологический бот (18+). Здесь он работает как веб-чат в браузере. Сценарий взят из `numero_mindmap.pdf`.

## Запуск

Двойной клик по `run.bat` или в терминале:

```bash
python -m uvicorn web.server:app --host 127.0.0.1 --port 8765
```

Открыть http://localhost:8765. Первый раз: `pip install -r requirements.txt`.

## Тесты

```bash
python -m pytest -q
```

## Где что лежит

- `bot/flow.py`: весь сценарий (кнопки, шаги, оплата, подписка). Про веб и Telegram не знает.
- `bot/numerology.py` и `content/*.json`: расчёты и тексты-заглушки. Экспертную методику подключать здесь.
- `bot/texts.py`: фразы бота.
- `bot/config.py`: цены, ссылка на канал, пауза «3 минуты».
- `web/`: чат в браузере и панель разработчика.
- `data/`: база SQLite и PDF, «отправленные на почту».

## Настройки через переменные окружения

- `NUMERO_LOADING_SECONDS`: реальная пауза после «3 минуты, готовлю информацию» (по умолчанию 5, в бою 180).
- `NUMERO_CHANNEL_URL`, `NUMERO_BOT_LINK`, `NUMERO_SUPPORT_URL`: ссылки на канал, на бота и на аккаунт техподдержки.

## Перенос в Telegram

Весь вывод идёт через интерфейс `Sender` (`bot/models.py`). Для Telegram нужен свой `Sender` (кнопки `cb`, `url`, `pay`, `share` ложатся на inline-кнопки), вызовы `bot.submit(uid, kind, data)` из обработчиков сообщений и нажатий, и платёжный вебхук, который вызывает `bot.submit_payment(uid, order_id, ok)`. Почта подменяется классом с методом `send_pdf` (`bot/mail.py`).
