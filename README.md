# Базовый код человека: прототип бота

Развлекательный нумерологический бот (18+). Здесь он работает как веб-чат в браузере, похожий на Telegram. Сценарий взят из `numero_mindmap.pdf`.

Всё в демо тестовое: оплата и почта имитируются, тексты раскладов это заглушки.

## Попробовать онлайн

Запустить свой экземпляр бесплатно, без установки:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/p34820669-art/numero-bot)

Нажать кнопку, войти в Render (можно через GitHub), подтвердить. Через несколько минут появится ссылка вида `https://numero-bot-….onrender.com`, её можно отправлять тем, кто будет пробовать. Бесплатный сервер засыпает без нагрузки, первый заход после паузы грузится около минуты, а база и PDF сбрасываются при перезапуске.

## Запуск у себя

Нужен Python 3.12. Двойной клик по `run.bat` или в терминале:

```bash
pip install -r requirements.txt
python -m uvicorn web.server:app --host 127.0.0.1 --port 8765
```

Открыть http://localhost:8765.

Слева чат, справа панель разработчика (на телефоне открывается шестерёнкой): перемотка времени, письма, подарки, заказы и подписки. Перемотка времени своя у каждого посетителя, чужие чаты она не трогает.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

## Где что лежит

- `bot/flow.py`: весь сценарий (кнопки, шаги, оплата, подписки, подарки). Про веб и Telegram не знает.
- `bot/numerology.py` и `content/*.json`: расчёты и тексты-заглушки. Экспертную методику подключать здесь.
- `bot/texts.py`: фразы бота.
- `bot/config.py`: цены, ссылки, пауза «3 минуты».
- `web/`: чат в браузере и панель разработчика.
- `data/`: база SQLite и PDF, «отправленные на почту».

## Настройки через переменные окружения

- `NUMERO_LOADING_SECONDS`: реальная пауза после «3 минуты, готовлю информацию» (по умолчанию 5, в бою 180).
- `NUMERO_CHANNEL_URL`, `NUMERO_BOT_LINK`, `NUMERO_SUPPORT_URL`: ссылки на канал, на бота и на аккаунт техподдержки.
- `NUMERO_GIFT_LINK`: шаблон подарочной ссылки с `{code}`. На Render подставляется автоматически.

## Перенос в Telegram

Весь вывод идёт через интерфейс `Sender` (`bot/models.py`). Для Telegram нужен свой `Sender` (кнопки `cb`, `url`, `pay`, `share` ложатся на inline-кнопки), вызовы `bot.submit(uid, kind, data)` из обработчиков сообщений и нажатий, и платёжный вебхук, который вызывает `bot.submit_payment(uid, order_id, ok)`. Почта подменяется классом с методом `send_pdf` (`bot/mail.py`).
